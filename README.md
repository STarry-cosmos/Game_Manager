# Game Manager（游戏管理）

一个轻量级的 Windows 本地游戏库管理与启动器，基于 WPF + SQLite。支持添加本地游戏、自动计时、分类整理、归档与「记忆场景」截图收藏。

![展示](/exhibit.png "展示")

当前版本：**v0.20.3**

## 功能

### 游戏库管理
- 添加、重命名、删除本地游戏
- 自定义封面图，支持修改可执行文件路径
- 右键菜单：打开所在目录等快捷操作
- 点击卡片打开右侧详情栏，集中查看路径、分类、时长与操作入口

### 启动与计时
- 一键启动游戏，后台监控进程并累计游戏时长
- 记录上次游玩时间、添加日期与运行状态
- 启动器关闭后再次打开，可正确恢复仍在运行的游戏计时
- 可执行文件不存在时自动禁用启动按钮并提示原因，避免出现「界面显示游戏中但实际未启动」

### 浏览与整理
- 搜索游戏名称
- 多种排序：按名称 / 上次游玩 / 总时长 / 自定义排序（支持拖拽）
- 网格布局与列表布局一键切换，并记住上次偏好
- 左侧分类栏：全部、未分类、内置类型，以及自定义分类（增删改）
- 底部状态栏显示当前库的游戏数量与总游戏时长

### 归档与记忆场景
- 通关或暂不常玩的游戏可归档，与主库分开浏览
- 归档模式下支持「记忆场景」：为游戏添加截图并大图浏览
- 支持 1–5 星评分（归档展示对应奖牌样式）

### 设置与数据
- 设置中可管理自定义分类
- 可打开本地数据库目录，便于备份与迁移
- 「关于」中可查看当前版本号、项目地址与开源许可证

## 环境要求

- Windows 10 / 11
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)（开发与编译）
- 运行时，需安装对应的 [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)
- 经测试，发行版解压即可运行

## 快速开始

```bash
# 克隆仓库
git clone https://github.com/STarry-cosmos/Game_Manager.git
cd Game_Manager

# 还原依赖并运行
dotnet restore
dotnet run
```

也可以直接双击仓库根目录的 `run.cmd`，它会自动编译并启动（启动前会关闭仍在运行的旧实例，避免 exe 被占用导致编译失败）：

```bash
run.cmd          # Debug 编译并启动
run.cmd -b       # 只编译，不启动
run.cmd -r       # 使用 Release 配置
run.cmd -n       # 跳过编译，直接启动
run.cmd -h       # 查看全部选项
```

发布示例（单文件 / x86，可按需调整）：

```bash
dotnet publish -c Release -r win-x86 --self-contained false
```

## 数据存储

应用数据位于本机：

```
%LocalAppData%\GameLauncher\
├── GameLauncher.db    # 游戏库、时长、归档、记忆场景等
├── settings.json      # 排序方式、布局偏好、自定义分类等
└── Media\             # 封面与记忆场景图片副本（相对路径存储）
```

可在应用内「设置 → 打开数据库目录」快速定位该文件夹。

## 项目结构

```
Game_Manager/
├── Views/          # 窗口与对话框（设置、重命名、分类、记忆场景等）
├── ViewModels/     # 主界面与游戏项逻辑
├── Models/         # 领域模型
├── Data/           # SQLite 与 settings.json 读写
├── Services/       # 进程监控与计时
├── Converters/     # XAML 值转换器
├── Helpers/        # 媒体文件托管、版本信息、UI 辅助
├── img/            # 内置图标与奖牌素材
└── run.cmd         # 一键编译并启动
```
