# Game Manager

一个轻量级的 WPF 桌面应用程序，用于通过 SQLite 持久性管理和启动游戏。

## 功能

- 添加、重命名和删除游戏
- 自动启动游戏并跟踪游戏时间
- 保留运行时间、上次玩时间和游戏状态
- 支持自定义封面图标和右键单击上下文操作
- 使用 MVVM 和本地 SQLite 存储构建
